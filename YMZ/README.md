# YMZ module

Build with `cargo build -p ymz --release --locked` and put `ymz-module` (or `ymz-module.exe`) beside `module.json` in `modules/ymz` next to `mz`. Run `mz login YMZ` to open the token site and paste a Yandex Music OAuth token into the terminal. `YM_TOKEN` also works. See the [module protocol](../README.md#write-a-module).
