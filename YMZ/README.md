# YMZ module

Build with `cargo build -p ymz --release --locked` and put `ymz-module` (or `ymz-module.exe`) beside `module.json` in `modules/ymz` next to `mz`. Provide a Yandex Music OAuth token in `~/.config/ymz/token`, `%APPDATA%\ymz\token`, or `YM_TOKEN`. See the [module protocol](../README.md#write-a-module).
