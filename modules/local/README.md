# Локальная папка

Нужны `ffmpeg` и `ffprobe` в PATH (Linux и Windows). Настройки можно менять до запуска:

```sh
mz set local path "$HOME/Music"
mz settings local
mz local
```

Переключение уже запущенного плеера: `mz switch local`. `mz set local path "/другая папка"` применяет новую папку и сбрасывает очередь активного local. Предзагрузка одного следующего трека сохраняется.

| Настройка | По умолчанию | Значение |
| --- | --- | --- |
| `path` | пусто | Существующая музыкальная папка; пробелы берите в кавычки |
| `recursive` | `true` | Включать подпапки |
| `hidden` | `false` | Включать скрытые файлы/папки |
| `shuffle` | `false` | Перемешивать библиотеку при заполнении очереди |
| `scan_limit` | `10000` | Максимум проверяемых файлов и папок; 1–100000 |
| `probe_timeout` | `5` | Лимит определения одного файла, 1–30 секунд |
| `ffmpeg`, `ffprobe` | имена программ | Можно задать абсолютные пути |
| `fluidsynth` | `fluidsynth` | Рендерер MIDI |
| `soundfont` | пусто | Существующий SF2/SF3 банк для MIDI |

Расширения не ограничены списком: файл проверяется по содержимому. Поддерживаются аудиоформаты, доступные установленной сборке FFmpeg: FLAC, WAV, MP3/MP2, AAC/M4A/ALAC, Ogg/Vorbis/Opus, WMA, AIFF, AU, VOC, WavPack, APE, TTA, CAF, AC3, ADPCM и другие. Для MOD/XM/S3M/IT и других трекерных форматов нужна сборка FFmpeg с `libopenmpt`. Проверка возможностей: `ffmpeg -demuxers` и `ffmpeg -decoders`. Неизвестные, повреждённые и защищённые DRM файлы не становятся воспроизводимыми автоматически.

MIDI определяется по заголовку, рендерится через FluidSynth и требует банк инструментов:

```sh
mz set local soundfont "/путь/GeneralUser.sf2"
```

SID и другие специализированные форматы, отсутствующие в FFmpeg и FluidSynth, требуют отдельного декодера; обещания поддержки буквально каждого существующего формата нет.

Сканирование использует до восьми ffprobe одновременно. Индекс метаданных лежит в `~/.cache/mz-local/index.json` (с учётом XDG; Windows — LOCALAPPDATA). Неизменённые файлы определяются по размеру и времени изменения. Имена треков берутся из тегов, затем из имени файла. Символические ссылки не обходятся; воспроизведение за пределами выбранной папки запрещено. Очень большая библиотека может потребовать повторного сканирования после 90-секундного лимита протокола; промежуточный индекс сохраняется.

Настройки: `~/.config/mz-local/settings.json` (XDG/APPDATA). Аудио преобразуется FFmpeg в FLAC для декодирования хостом; текущий и следующий треки хранятся во временных файлах, постоянной копии библиотеки нет. Сохраняются общие ограничения хоста: 512 MiB на трек и 180 секунд на подготовку аудио.
