# Icecast: прослушивание станций

Нужен `ffmpeg` в PATH. Модуль слушает HTTP(S) mountpoint Icecast/Shoutcast и другие прямые аудиопотоки; вещание на сервер не выполняет.

```sh
mz set icecast url "https://radio.example.org:8443/live.ogg"
mz settings icecast
mz icecast
```

Радио воспроизводится сразу после заполнения буфера, без скачивания бесконечного потока в файл. PCM 48 kHz/stereo хранится в ограниченном буфере памяти; для радио предзагрузка второго подключения отключена. Пауза приостанавливает воспроизведение с ограниченным буфером, поэтому после долгой паузы для возвращения к прямому эфиру используйте `mz next`. Перемотка для радио недоступна. В статусе и MPRIS показывается название станции; динамические ICY названия отдельных песен пока не отображаются.

| Настройка | По умолчанию | Значение |
| --- | --- | --- |
| `station` | `default` | ID станции, которую редактируют настройки ниже |
| `stations` | одна пустая станция | JSON список `{id,name,url,username,password}`; до 200 станций |
| `url` | пусто | Полный HTTP(S) URL выбранной станции |
| `server` | — | Изменить origin выбранной станции, сохранив mountpoint |
| `mountpoint` | — | Путь `/live.mp3` на уже заданном сервере |
| `name` | `Icecast` | Отображаемое имя выбранной станции |
| `username`, `password` | пусто | HTTP Basic авторизация выбранной станции; password скрыт в `settings` |
| `proxy` | пусто | HTTP proxy URL; пустая строка отключает |
| `user_agent` | `MusicZero/0.3` | HTTP User-Agent |
| `reconnect` | `true` | Переподключение после EOF, сетевых сбоев, 429 и 5xx |
| `reconnect_delay_max` | `5` | Максимальная задержка попыток FFmpeg, 1–60 секунд |
| `timeout` | `15` | Таймаут сетевого чтения, 1–120 секунд |
| `buffer_ms` | `1000` | Стартовый буфер и ограниченная очередь PCM, 250–10000 мс |
| `tls_verify` | `true` | Проверять сертификат HTTPS |
| `ca_file` | пусто | Дополнительный CA-файл для собственной PKI |
| `ffmpeg` | `ffmpeg` | Имя или абсолютный путь к FFmpeg |

Пример нескольких станций (настройте собственные URL):

```sh
mz set icecast stations '[{"id":"one","name":"Первая","url":"https://radio.example.org/one.mp3"},{"id":"two","name":"Вторая","url":"https://radio.example.org/two.ogg"}]'
mz icecast
mz playlists
mz playlist two
mz set icecast station two
mz set icecast buffer_ms 1500
```

Плейлист `default` означает станцию из настройки `station`; ID конкретной станции выбирается через `mz playlist`. Настройки активного модуля применяются с переподключением и отменой старого потока. После завершения FFmpeg хост также повторяет запрос с задержкой. Неправильный URL или отказ в авторизации показываются в stderr. Для пароля используйте HTTPS. Показанный в настройках `***` — маска, не настоящий пароль.

Настройки сохраняются атомарно с правами `0600` на Unix: `~/.config/mz-icecast/settings.json` (XDG/APPDATA). На Unix FFmpeg заменяет процесс модуля, поэтому остановка/переключение закрывает подключение. Windows требует установленных FFmpeg binaries; сборка на Windows проверяется CI.
