# Spotify: библиотека и звук по Premium-сессии

Модуль не нужен `yt-dlp` или FFmpeg. Он читает библиотеку через Spotify Web API и выдаёт звук собственной сессией Librespot (расшифровка Ogg Vorbis/MP4), поэтому воспроизведение доступно только для аккаунтов Spotify Premium.

## Настройка

1. Создайте приложение на [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard). Для приложений Development Mode владелец обязан иметь подписку Premium; соберите и запишите `client_id`.
2. В настройках приложения добавьте Redirect URI ровно `http://127.0.0.1:8910/callback`.
3. Выполните:

```sh
mz set spotify client_id <client_id>
mz login spotify
mz spotify
```

`mz login spotify` открывает страницу OAuth (PKCE), слушает ответ на локальном порту 30 секунд и сохраняет токены в `~/.config/mz-spotify/tokens.json` (`%APPDATA%\mz-spotify\tokens.json` в Windows, файл `0600` в Linux). Смена `client_id` делает сохранённый вход недействительным — войдите повторно.

## Плейлисты и звук

`likes` (`Мне нравится`), `recent` (`Недавно прослушанное`) и `top` (`Любимые треки`) всегда доступны; следом идут плейлисты аккаунта (`playlist:<id>`) и сохранённые альбомы (`album:<id>`).

Звук скачивается и расшифровывается на их CDN с носимой битностью через Librespot; Ogg Vorbis и MP4-подкасты передаются в плеер без перекодирования. Сессия Librespot открывается заново на каждый трек, поэтому первый трек после запуска появляется через несколько секунд.

| Настройка | По умолчанию | Значение |
| --- | --- | --- |
| `client_id` | пусто | 32 шестнадцатеричных символа из Dashboard |
| `redirect_uri` | `http://127.0.0.1:8910/callback` | Только loopback `/callback`; должен совпадать с приложением |
| `bitrate` | `320` | `96`, `160` или `320` кбит/с Vorbis |
| `explicit` | `true` | `false` скрывает треки с меткой explicit |

## Ограничения

- Воспроизведение требует Premium. Бесплатные аккаунты и новые приложения Development Mode не получат доступ к части эндпоинтов; аудио эпизодов зависит от подписки.
- Содержимое плейлистов Scope:"items" возвращается только для собственных плейлистов или тех, где вы соавтор; подписные плейлисты недоступны для чтения списком (ограничение API февраля 2026).
- Токены хранятся локально; клиентский `client_id`, пароли не хранятся вовсе.
