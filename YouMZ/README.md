# YouMZ module

Build with `cargo build -p youmz --release --locked` and put `youmz-module` (or `youmz-module.exe`) beside `module.json` in `modules/youmz` next to `mz`. Install `yt-dlp` on `PATH`, then run `mz login youmz` and `mz start youmz`. `YOUMZ_COOKIE` is also supported. See the [module protocol](../README.md#write-a-module).
